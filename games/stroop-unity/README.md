# 색깔 헷갈림 — 스트룹(Stroop) 미니게임 (Unity)

두뇌 트레이닝 앱 스타일의 스트룹 테스트 미니게임입니다. 고령자도 플레이할 수 있도록 규칙을 단순하게 했습니다.
화면에 **색 이름**이 **다른 색 잉크**로 표시되고, 글자를 읽지 말고 **글자가 칠해진 색**을 고릅니다.

예: <span style="color:#1E63D6">빨강</span> (파란 잉크) → 정답은 **파랑**

## 설치 & 실행 (1분)

1. Unity 2021.3 LTS 이상 프로젝트(2D/3D 상관없음)를 엽니다.
2. `Assets/StroopGame` 폴더를 프로젝트의 `Assets/` 아래로 복사합니다.
3. 새 씬에서 **빈 GameObject**를 만들고 `StroopGame` 컴포넌트를 붙입니다.
4. **Play** — 타이틀 / 게임 / 결과 화면 UI가 전부 코드로 자동 생성됩니다.

> 씬에 EventSystem이 없으면 자동으로 만들어 줍니다 (구/신 Input System 모두 대응).

### 한글 폰트
에디터에서는 OS 폰트 대체로 한글이 보이지만, **모바일/WebGL 빌드에서는 한글이 깨질 수 있습니다.**
[Noto Sans KR](https://fonts.google.com/noto/specimen/Noto+Sans+KR) 같은 한글 `.ttf`를 프로젝트에 넣고
`StroopGame` 인스펙터의 **Font** 칸에 지정하세요.

## 게임 규칙

- 제한 시간 **45초**, 오답 시 **-1초**
- 점수 = 기본 100 + 콤보 보너스(콤보당 +10, 최대 +100) + 속도 보너스(0.8초 미만 +50 / 1.2초 +30 / 1.8초 +10)
- 색은 **빨강·파랑·초록·노랑 4가지로 고정**, 문제는 **"색깔" 문제만** 나옵니다.
- 정답 5개마다 레벨 업. **난이도는 한 문제에 답할 수 있는 시간으로만 올라갑니다.**
- 시간 안에 답하지 못하면 오답으로 처리됩니다 (콤보 초기화, -1초).

| 레벨 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| 문제당 제한 시간 | 5.0초 | 4.5초 | 4.0초 | 3.5초 | 3.0초 | 2.5초 | 2.0초 |

- 시간 값은 `StroopLogic.cs`의 `StartAnswerTime`, `AnswerTimeStep`, `MinAnswerTime`에서 바꿀 수 있습니다.

- 보기에는 항상 **함정 보기**(글자가 뜻하는 색)가 포함되어 스트룹 간섭을 유도합니다.
- 결과 화면: 점수, 최고 기록(PlayerPrefs 저장), 정답 수, 정확도, 평균 반응 속도, 최대 콤보

## 인스펙터 설정값

| 항목 | 기본값 | 설명 |
|---|---|---|
| Round Duration | 45 | 제한 시간(초) |
| Wrong Penalty Seconds | 1 | 오답 시 감소 시간 |
| Correct Per Level | 5 | 레벨업에 필요한 정답 수 |
| Feedback Delay | 0.18 | 답 선택 후 다음 문제까지 대기 |
| Font | (없음) | 한글 폰트 |
| Palette | 빨강·파랑·초록·노랑 | 색 이름/색상 (앞의 4개를 사용) |

## 코드 구조

```
Assets/StroopGame/Scripts/
├── StroopLogic.cs      # 문제 생성기, 레벨 난이도, 점수 규칙 (순수 로직)
├── StroopUIFactory.cs  # uGUI 오브젝트를 코드로 생성하는 헬퍼
└── StroopGame.cs       # 게임 흐름(타이틀→카운트다운→플레이→결과), HUD, 연출
```

`StroopGenerator`는 MonoBehaviour와 분리되어 있어서 시드를 주면 같은 문제열을 재현할 수 있고,
EditMode 테스트로 검증하기 쉽습니다.
